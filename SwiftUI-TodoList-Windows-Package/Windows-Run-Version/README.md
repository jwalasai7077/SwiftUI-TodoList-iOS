# TaskFlow — Windows-run version

This is a Windows-friendly browser implementation of the Todo List app's core workflow. It is included so you can open and demonstrate the functionality on a Windows laptop without Xcode.

## Run it (no installation required)
1. Extract the ZIP package.
2. Open `Windows-Run-Version`.
3. Double-click `START-WINDOWS.bat` (or open `index.html` in Chrome/Edge).
4. Add tasks, edit them, mark them complete, search, filter by priority, sort, and switch dark mode.

Tasks are saved in your browser's local storage on that computer.

## Important distinction
This folder is a browser-based Windows demo, not a native iOS app. It does not compile or run SwiftUI. The original SwiftUI/Xcode source is preserved in `../Original-iOS-Xcode-Project/` and must be opened with Xcode on macOS to build and run as an iPhone app.
